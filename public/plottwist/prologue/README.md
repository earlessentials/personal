# THE PROLOGUE

Original bilingual narrative card experience for PLOT TWIST, by Pearling Lim.

This folder is served directly at /plottwist/prologue/ by the existing GitHub Pages workflow. It is self-contained and does not replace other website pages.

The app stores selections in browser-local storage, shows the pre-reveal disclaimer, and loads the reading module only after the participant confirms the reveal. It never redirects to a ChatGPT-hosted site and uses no ChatGPT runtime or external language-model service. A static hosting environment cannot enforce server-side secrecy against someone deliberately downloading public source files; normal selection screens receive no card names, meanings, or categories. Do not add server keys, account credentials, or customer information to this public folder.

The source modules are readable ES modules. The app module contains the selection and reading UI; the session module handles persistence and concealed stages; the reading module contains card definitions, interaction rules, narrative writing, and original artwork. The hero artwork is an original generated asset.

PDF export is intentionally unavailable. Copy and native sharing remain supported.
